# Page Flip - Essai Catalogue KENI

Projet d'intégration de la bibliothèque **StPageFlip** sur une page web personnelle.

## 📖 À propos

Ce projet utilise **St-Page-Flip**, une bibliothèque JavaScript moderne pour créer des effets de feuilletage de pages interactifs et réalistes.

## 🚀 Installation et Utilisation

### Étape 1: Cloner le dépôt
```bash
git clone https://github.com/DAVY2603/page-flip.git
cd page-flip
```

### Étape 2: Structure du projet
```
page-flip/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── images/
│   └── (vos images pour le catalogue)
└── README.md
```

### Étape 3: Intégration de StPageFlip

Consultez la [documentation officielle de StPageFlip](https://github.com/Nillyz/page-flip)
